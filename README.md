### 🚀 Flagship Systems & Architecture

#### 🛡️ [PSIRT-PAL — CVE Resolution Agent](https://manjunath-urs.com/#work)
* **What it is:** Full-stack, spec-driven agentic AI assistant built for product security engineering.
* **Architecture:** React 18 + TypeScript frontend (Material UI, Zustand, TanStack Query), FastAPI backend, PostgreSQL, SQLAlchemy, Celery & Redis task queues, JWT authentication, and LLM tool-calling capabilities.
* **Impact:** Reduced CVE triage and assessment from **2–3 days of manual analysis down to 1–2 minutes** across 300–450 CVEs for 9 Dell product lines.

#### 🧠 [SAT — AI-Powered STIG Compliance Analyzer](https://manjunath-urs.com/#work)
* **What it is:** Two-layer semantic compliance engine for automated DISA STIG benchmark analysis and rule difference classification.
* **Architecture:** Sentence Transformers (`all-mpnet-base-v2`) with FAISS in-memory vector search, backed by multi-level rule thresholds and LLM-generated developer remediation insights (Mistral-7B / fine-tuned Llama-8B).
* **Impact:** Cut STIG benchmark analysis time from **2–3 days per component to a few hours**, eliminating manual human error across releases.

#### ⚙️ [VAST — Factory Automation & CI/CD Platform](https://manjunath-urs.com/#work)
* **What it is:** End-to-end datacenter orchestration and factory deployment automation platform.
* **Architecture:** Jenkins CI/CD pipelines, Python backend services, and modular Ansible provisioning workflows integrated with a zero-overhead automated regression testing framework.
* **Impact:** Eliminated ~50% pre-merge playbook breakage, enabling parallel feature delivery across distributed teams.

#### 👁️ [SnapMap — Multimodal UI & Command Discovery Agent](https://manjunath-urs.com/#work)
